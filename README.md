# Mini Kasir OOP - Versi Sederhana

Project satu file untuk mini project PBO semester 3.

## Cara menjalankan

Buka terminal VS Code di folder project:

```bash
php -S localhost:8000
```

Buka browser:

http://localhost:8000

## Akun

- Admin: `admin` / `123`
- Kasir: `kasir` / `123`

## Konsep OOP

- Class dan Object
- Property
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism

## Catatan

Data menu dan transaksi disimpan di session browser, bukan database. Cocok untuk demo mini project dan masih sederhana untuk dipahami mahasiswa semester 3.
